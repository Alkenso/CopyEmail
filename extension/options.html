Website access

Show copy icons everywhere except on websites matching the list below.

One hostname pattern per line. Only * and ? are supported as wildcards:

  • * matches zero or more characters.
  • ? matches exactly one.

Matching ignores case and covers the entire hostname. Do not include https://, paths, or ports.

example.com matches that website only.

*.example.com matches subdomains; add example.com separately for the main website.

mail?.example.org matches mail1.example.org, but not mail12.example.org.

An empty list enables CopyEmail everywhere.

Settings are saved in this browser and apply to open tabs immediately. Rules use the website in the address bar, including its embedded frames.
